🚀 Exportateur YouTube

Pourquoi rien ne se passe ?
1. Vous devez être sur la page "Tous les abonnements".
2. Sur mobile, vous devez taper le nom du favori dans la barre d'adresse, pas juste cliquer dessus.
Étape 1 : Allez sur la bonne page
Ouvrez YouTube et allez ici :
youtube.com/feed/channels
Étape 2 : Créez le "Favori Magique"
1. Copiez ce code : 2. Créez un favori dans votre navigateur (n'importe quelle page).
3. Modifiez-le : nommez-le "EXTRAIRE" et collez le code copié dans le champ URL/Adresse.
Étape 3 : Lancez l'exportation
1. Sur la page YouTube, cliquez sur la barre d'adresse.
2. Tapez EXTRAIRE.
3. Cliquez sur le favori qui apparaît avec une petite étoile ⭐️ ou une loupe.
4. Attendez l'alerte ! Le téléphone va défiler tout seul puis télécharger le fichier.
